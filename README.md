# 🍺 AI 酒館

[![下載 Windows 版](https://img.shields.io/badge/%E4%B8%8B%E8%BC%89-Windows%20%E7%89%88-2ea44f?style=for-the-badge&logo=github)](https://github.com/GornBear/Gorn-AiTavern/releases/latest)

在本機執行的 AI 角色扮演聊天程式，類似 SillyTavern：基於 Node.js 的小型伺服器加上瀏覽器介面。
簡單方便的圖形化介面，不用準備複雜的指令，輕鬆匯入、編輯角色卡，跟喜歡的角色聊天。
連接自己的 API，不用受其他聊天網站供應商限制，可以接本地自架 AI，也能使用常見的 API（OpenAI 相容格式、Gemini、Claude）。
（本軟體使用 [Claude Code](https://claude.com/claude-code) 開發）

> 預設提示詞允許成人內容，僅供成年人使用。

## 啟動

1. Windows 雙擊 **`AI 酒館.exe`**（有自己的圖示、不顯示黑色命令視窗；找不到 Node.js 或啟動失敗時會跳出說明）；想看伺服器紀錄可以改用 `start.bat`。macOS / Linux 執行 `sh start.sh`
   - `AI 酒館.exe` 用自己所在的資料夾找程式，整個資料夾搬到哪裡都能用，不需要捷徑；請讓它和 `launch.js` 放在同一層
   - 啟動時的輸出寫在 `data/launcher.log`，打不開時可以查看
2. 程式會用 Chrome（沒有 Chrome 時改用 Edge，都沒有時用預設瀏覽器）的「應用程式模式」開成獨立視窗（沒有網址列與分頁）；**關閉視窗即結束伺服器**。視窗會記住上次的位置、大小與是否最大化（存在 `data/window.json`，刪掉就回到預設大小）
3. 第一次啟動會自動執行 `npm install`（只安裝 Claude 用的 `@anthropic-ai/sdk`，伺服器本身只使用 Node 內建模組）

### Node.js

- 需要 [Node.js](https://nodejs.org/) 18 以上版本（Windows 可執行 `winget install OpenJS.NodeJS.LTS`）。電腦上有安裝時一律優先使用安裝的版本
- **不想安裝也可以**：資料夾裡有內附的 Node.js（`runtime/node.exe`，Releases 下載的分享版都有附）時，`AI 酒館.exe` 找不到已安裝的 Node.js 會詢問要「使用內附版本執行」還是「前往下載 Node.js」，並說明內附版本的限制（不會自動更新安全性修正、防毒軟體可能攔截、`node_modules` 要完整、只支援 64 位元 Windows）；可以勾選記住選擇（存在 `data/launcher.ini`，刪掉就會再詢問）
- 已經安裝 Node.js 時用不到內附版本，可以在「設定 → 資料 → 內附的 Node.js」按「刪除」省下約 95 MB；要放回來時按「重新建立」（從這台電腦安裝的 Node.js 複製一份，更新電腦上的 Node.js 後也可以用它更新）

## 玩家存檔：`userdata/`

角色卡、對話、世界、世界書、設定、模型設定檔、API 金鑰、頭像／背景圖與自動備份**全部放在專案第一層的 `userdata/` 資料夾**，和程式分開。更新程式時只要保留這個資料夾；要整個搬家也可以直接複製它（或用設定頁的「匯出」）。

## API 金鑰

金鑰**不寫在程式碼裡**，讀取順序：

1. 環境變數：`OPENAI_API_KEY`、`GEMINI_API_KEY`、`ANTHROPIC_API_KEY`
2. `userdata/config.json`（在「⚙️ 設定 → API 設定」填寫後自動寫入，也可以把 `config.example.json` 複製成 `userdata/config.json` 修改）

伺服器不會把金鑰回傳給瀏覽器。

> ⚠ **請勿將 `userdata` 資料夾底下的 `config.json`（或整個 `userdata` 資料夾）分享給他人**，裡面以明文存著你的 API 金鑰。要分享角色卡請用角色編輯裡的「匯出 PNG／JSON」，要搬家請用「設定 → 資料 → 匯出全部資料」，這些都不含金鑰。若不慎傳出，請立即到 API 供應商的網站撤銷（刪除）這把金鑰並重新產生，再填入新的金鑰，以免被盜用而產生費用。

**模型設定檔**：在「設定 → API 設定 → 模型設定檔」按「另存新設定檔」，可以把目前的供應商、API 位址、模型、思考程度、生成參數（含上下文長度）連同金鑰存成一個設定檔，之後在設定頁或對話頁右上角的模型選單一鍵切換。一定有一個使用中的設定檔，「儲存」只更新它；已經存過的金鑰顯示成遮罩符號，直接輸入新的就會取代，按眼睛按鈕可以顯示。每個供應商都附有填寫步驟（先填 API 位址與金鑰，再按「取得模型清單」選模型）。

## 支援的 API

| 供應商 | 說明 |
|---|---|
| OpenAI 相容 | OpenAI、OpenRouter、DeepSeek、Groq、LM Studio（`http://127.0.0.1:1234/v1`）、Ollama（`http://127.0.0.1:11434/v1`）等，只要支援 `/chat/completions` 串流即可；「重複懲罰」大於 1 時才會送出 `repetition_penalty`（OpenAI 官方不支援，請保持 1） |
| Google Gemini | 透過 Gemini 原生 API，金鑰在 Google AI Studio 取得；按「取得模型清單」選模型。安全審查的五個類別（騷擾、仇恨言論、色情內容、危險內容、公民誠信）都設為 `OFF`；`PROHIBITED_CONTENT` 是 Google 不開放調整的政策過濾，無法關閉。被擋下時會顯示是哪一類、是送出的內容還是 AI 的回覆觸發的 |
| Anthropic Claude | 使用官方 SDK，預設 `claude-opus-5-5`，可調整 effort，並開啟自動提示快取與拒答備援 |

## 功能

### 角色與對話

- **第一次啟動的引導**：首頁會跳出引導，提醒先到「設定 → API 設定」填 API（必要）、到「設定 → 使用者」設定名字（建議），完成的步驟會標「已完成」；按「知道了」之後不再出現
- **首頁**：以封面卡片顯示所有角色，可「繼續」最近的對話、開新對話或進入角色設定；上方列出最近的對話可一鍵進入
- **封面與頭像**：封面是角色卡圖片（匯入 PNG 時自動設定，匯出 PNG 也用它）；對話中顯示頭像，沒有設定專屬頭像時使用封面
- **角色卡**：匯入 PNG / JSON（V1、V2 `chara_card_v2`、V3 `chara_card_v3`，也支援把開場白放在 `chat_history` 的網站匯出格式）；可拖放檔案匯入；匯出 PNG（資料嵌入圖片）或 JSON
- **角色卡編輯器**：名稱、描述、個性、情境、開場白、備用開場白、系統提示、後置指令、對話範例、作者備註、標籤、頭像、內嵌世界書，各欄位顯示 token 估算
  - 開場白用對話頁的排版編輯：每個開場白（主要、備用）是一個區塊，可以依序放好幾則角色、旁白或你的台詞；匯出給其他程式時合併成文字，對方一樣讀得懂
  - 角色詳情的「開始對話」下方顯示卡片的 token 估算（角色設定、主要開場白、內嵌世界書）
- **對話頁**：左側列出該角色的每段對話，可直接改名、刪除；訊息下方有重新生成、編輯、複製、分支、刪除
- **聊天**：串流輸出、停止、重新生成（保留多個版本可左右切換）、繼續、編輯、刪除、從某則訊息分支、多段對話紀錄；每段對話各自記住輸入框的草稿；清空聊天前會把原本的對話放進垃圾桶（可以還原）
- **你扮演的 NPC、你寫的旁白**：輸入框旁的身分選單可以選「我」、「旁白（我自己寫）」或「NPC：名字」（＋新增 NPC，只要名字，台詞由你寫）。這些訊息用旁白的外觀顯示、名字旁標「NPC・你扮演」或「你寫的」，重新生成不會動到；送給 AI 時會標上身分，並要求 AI 不要替 NPC 說話，整理記憶時 NPC 的話也不會被記成你的設定。「只加入」按鈕或 Alt+Enter：只加入訊息、不讓 AI 回應。NPC 名單在「對話設定」可以新增、改名（舊訊息一起改）與移除；編輯訊息時也可以改成用哪個身分說的
- **搜尋**：對話頁左側的搜尋框輸入兩個字以上，也會搜尋所有對話的訊息內容，點結果直接跳到那則訊息
- **長對話**：打開對話時先顯示最近 100 則（可設 50～500 則或全部），往上捲到頂端自動載入更早的
- **訊息排版**：支援安全的 HTML（`<details>`/`<summary>` 摺疊、清單、表格、標題、`<p>` 段落、引用、顏色等），會自動移除腳本、事件屬性、iframe 與 `javascript:` 連結；``` 程式碼區塊內的內容不轉換；`*動作*` 與「台詞」照樣上色

### 大世界（多角色）

首頁「世界」欄位的「創建世界」可以把多張角色卡放進同一個世界。

- **成員**：世界只記錄成員是哪些角色，對話時才讀取角色卡；每個成員讀取「角色設定、個性、台詞範例」，不使用角色的開場白與情境
- **角色卡的系統提示**：可選擇完整套用、不套用或自訂。點世界設定裡的角色頭像，「完整套用」時下面會顯示完整內容；直接修改就自動改成「自訂」，切回「完整套用」會重新帶入完整內容（捨棄修改）
- **世界設定**：「基本」分頁寫世界觀（時代、地點、勢力、力量體系、歷史、文化…），每一輪都會送給角色、旁白與導演；只偶爾提到的細節建議放進世界專屬的世界書用關鍵字觸發
- **開場白與提示詞**：開場白可以由旁白、任一位角色或你自己依序說好幾則，各自用自己的頭像與對話框；額外的系統提示詞與後置指令由你自己寫
- **世界書**：「世界書」分頁列出成員角色卡內嵌／連結的世界書（可各自開關），也可以為世界連結世界書或加入世界專屬的條目
- **封面**：預設為風景圖，可以更換。世界的對話一樣有記憶功能
- **發言模式**：
  - **輪流發言**（預設）：每個角色各自生成、各自的頭像與對話框。每輪先由「導演」判斷誰在場（不在場的角色不會發言，只有劇情需要時才安排登場），再規劃方向、發言順序與各角色的意圖，每個角色只看得到自己那一行；後面發言的角色會接著前面角色已經發生的事。沒人在場時由旁白描寫，你也可以隨時在發言列點「旁白」呼叫；發言列上不在場的角色顯示成淡色，點他＝讓他登場
  - 可設定每輪最多幾位接話、插話機率、插話時是否截斷上一位（預設開啟）；輸入框上方的頭像可直接指定誰說話，生成中點別人＝插話
  - **旁白統一**：一次寫出所有角色
- **整理角色卡規則（AI）**：「提示詞」分頁的按鈕。把各角色系統提示裡共用的扮演規則（不替玩家說話、回應長度等）交給 AI 挑出來，加到「規則與文風」的最後面，每位角色只保留自己的規則並自動改成「自訂」。按下前會顯示使用的模型與預估用量，結果先顯示預覽（可修改、可對照原文、列出各角色要求不同的規則），按「套用」寫回編輯器，按「儲存」才存檔；角色卡本身不會被修改

### 提示詞與記憶

- **提示詞組裝**：主要系統提示 + 角色卡系統提示（兩者都送出；角色卡寫 `{{original}}` 可指定主要系統提示的位置）→ 世界書（角色前）→ 角色設定 → 世界書（角色後）→ 使用者人設 → 對話範例 → 長期記憶 → 聊天紀錄（依上下文長度裁切，含深度注入）→ 後置指令；支援 `{{char}}`、`{{user}}`、`{{original}}`、`{{time}}`、`{{date}}` 巨集。🔍 按鈕可檢視實際送出的內容
- **世界書**：關鍵字（可用 `/正則/`）、次要關鍵字、常駐條目、插入位置（角色前/後/指定深度）、排序、掃描深度、token 預算（最少 1024）、遞迴掃描（各本各自設定，條目可設「不會被遞迴觸發」「內容不觸發其他條目」）；編輯時上方是可搜尋、可橫向捲動的條目標籤列，下方只顯示選中的條目；可設為全域、連結到單一角色，或內嵌在角色卡；可匯入 SillyTavern 世界書 JSON
- **記憶**：每段對話各自保存「劇情摘要＋重點」，放在聊天紀錄之前，舊訊息被上下文裁掉後 AI 仍記得。對話頁右上角「對話設定 → 記憶」可檢視、手動編輯、讓 AI 整理新訊息或全部重新整理；「全部重新整理」或手動儲存前會留一版，可以「換回上一版」
- **上下文壓縮**（「設定 → 提示詞設定 → 記憶與上下文壓縮」）：聊天紀錄超過可用空間（上下文長度扣掉回應、系統提示、角色設定與記憶）的門檻（預設 70%）時，把較舊的對話整理進記憶並不再送出原文，只保留最近一段（預設 35%），切點一律在「你的發言」前面；被移出的對話一定已經在記憶裡。通常在回應完成後於背景壓縮，下一次送出不用等；之後好一陣子提示詞開頭都不變，快取可以重用。存檔裡的原文都會保留。關閉自動壓縮時，聊天紀錄太長就只依上下文長度裁掉最舊的部分
- **對話語言**：「設定 → 提示詞設定」最上方可選擇要求模型使用的語言（繁體中文、简体中文、English、日本語；預設繁體中文），角色、旁白與整理記憶都會帶上這個要求。這只是對模型的要求，並非對所有模型都有效
- **思考程度**：模型選單左邊的思考選單只對這段對話有效：跟隨設定、關閉、低、中、高、模擬思考（給不會思考的模型用：提示詞要求先在 &lt;thinking&gt; 裡簡短規劃再回覆，思考收進思考區塊、之後不再送出；同時關閉模型原生的思考，避免兩種思考疊在一起）。Claude 在「設定 → API 設定」也可以設定思考開關，開啟時會顯示思考過程
- **節省 token**：聊天紀錄中只保留最近幾則訊息的 `<details>` 狀態欄（預設 3 則，可在「設定 → 提示詞設定」調整），更早的在送出前移除，畫面與存檔不受影響；大世界的導演只讀最近幾則（預設 20 則）
- **使用者設定檔**：「設定 → 使用者 → 使用者設定檔」可以把你的名字、人設與頭像存成設定檔，一鍵切換；使用中時換頭像、改名字或人設會一起更新。一定有一個使用中的設定檔（預設是「User」），名字不能空白。每段對話也可以在「對話設定」指定用哪一個
- **對話設定**：對話頁右上角（模型選單旁邊）的「對話設定」只對這段對話有效：上下文長度、創意發散度（Temperature）、回覆長度（最大回應 tokens）（留空＝跟隨目前的模型設定）、聊天紀錄最多送多少 tokens（預設角色對話 16k、大世界 32k）、目前每次送出的 token 數、這段對話的你（跟隨設定頁、選一個使用者設定檔，或只替這段對話自訂名字與人設）、使用哪些世界書、記憶、大世界每輪最多幾位角色接話、思考程度、檢視送出的提示詞、清空聊天；建立分支時一起帶過去

### 用量與連線

- **實際用量**：狀態列顯示這則的輸入／輸出 token 與這段對話的累計（含導演與整理記憶）
- **回應耗時**：每則 AI 回應的左下角顯示花了幾秒；滑鼠移上去可以看第一個字出現的時間、總共的時間、輸出速度（tokens／秒），大世界還有導演規劃的時間
- **自動重試**：連線失敗、請求太頻繁（429）、伺服器忙碌時等 2、4、8… 秒自動重試，次數上限可設定（0～5 次，預設 2 次）；已經開始輸出文字後才出錯就不重試
- **逾時**：API 超過 5 分鐘沒有送出新內容就中止（還沒產生文字時會自動重試）；「取得模型清單」20 秒逾時

### 存檔、備份與外觀

- **存檔**：全部存在 `userdata/` 資料夾（JSON 檔），聊天每次生成後自動儲存
- **備份與搬家**：每次啟動自動備份一次到 `userdata/backups`（和上一份相同時略過，預設保留 7 份）；「設定 → 資料」可以立即備份、還原、下載，或把全部資料匯出成一個檔案帶到別台電腦再匯入（匯入／還原前會先自動備份目前的資料）。備份與匯出都不含 API 金鑰。關閉酒館時會等生成中的回應存檔再備份一次
- **垃圾桶**：刪除的角色（連同對話）、大世界、世界書與單一對話會先移到 `userdata/trash/`，超過保留天數（預設 7 天，可選 1～30 天）自動清除。「設定 → 資料 → 垃圾桶」可以查看、還原、永久刪除單一項目或清空；還原對話前，它所屬的角色或大世界要還在
- **防止內容不見**：編輯器與設定頁有還沒儲存的修改時，關閉或離開前會先確認；刪除、清空這類確認視窗預設選「取消」。設定檔損毀時不會被空白設定蓋掉，畫面上方會提示並可以直接前往備份還原
- **外觀**：「設定 → 外觀」可以設定動畫、背景（星空、夜空漸層、純色或自訂圖片，圖片可調暗度）、主題色與字級；改動會立即預覽，按「儲存設定」才保存
- **釘選到工作列**：用 `AI 酒館.exe` 開啟後，在工作列的 AI 酒館按鈕按右鍵 →「釘選到工作列」，釘選的就是 AI 酒館（自己的圖示與名稱），點它會執行 `AI 酒館.exe`。用 `start.bat` 開的視窗會被當成 Chrome；資料夾搬家後要重新釘選一次
- **安全**：只接受來自本機、酒館自己頁面的請求，其他網站無法操作酒館或讀取設定

## 環境變數

- `PORT`：埠號（預設 8000）。被其他程式佔用時（例如 SillyTavern 預設也用 8000），會先確認是不是另一個 AI 酒館：是就直接打開它的視窗；不是就自動改用下一個空的埠（最多試到 +19）
- `HOST`：監聽位址（預設 `127.0.0.1`，只允許本機；若要讓區網裝置連線可設為 `0.0.0.0`，但沒有登入保護，請自行斟酌）
- `TAVERN_BROWSER`：指定開啟視窗用的瀏覽器路徑

## 開發

程式由作者與 Claude 透過 [Claude Code](https://claude.com/claude-code) 共同撰寫。

- `npm run server`：只啟動伺服器（不開視窗）
- `npm test`：用暫存資料夾與假的 AI 服務跑一遍 API 測試，不會動到你的資料
- **圖示**：原始檔是 `assets/icon.svg`。改了之後執行 `npm run icon`（產生 `assets/app.ico` 與 `public/icon.png`），再執行 `npm run build-launcher` 重新編譯 `AI 酒館.exe`（使用 Windows 內建的 C# 編譯器）
- `settings.json` 只記錄和預設不同的設定，沒改過的（例如內建提示詞）跟隨程式預設

```
